# Rot of Elizium

Форк SillyTavern с интеграцией Bridge — подключает LLM к игровому чату игры

## Возможности

- Получение сообщений из игрового чата (рядом, шёпот, радио, объявления)
- Фильтрация по именам персонажей и типам каналов
- Генерация ответа от выбранной карточки персонажа
- Автоматическая отправка ответа обратно в игру (или с подтверждением)



## Быстрый старт

```bash
npm install --production
node server.js
```

Открой `http://localhost:8000`, выбери персонажа, открой Bridge (иконка башни слева) и нажми «Найти клиент и подключить bridge».
